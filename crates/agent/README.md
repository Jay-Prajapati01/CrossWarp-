# Rust agent

Foundational session coordinator, ownership, QoS, trust, Windows DPAPI identity and trusted-peer persistence, authenticated async stream pairing, ephemeral TCP listener, mDNS publish/browse, and capability-rooted Shared Workspace file operations. Tests cover pairing over in-process streams and loopback TCP; physical multicast discovery has not been validated. The file API is local and not exposed through network RPC. Native input, IDD streaming, interactive window portals, desktop pairing UX, and a running paired session remain unimplemented. Run `cargo test --workspace` from the repository root; Windows tests exercise DPAPI and filesystem behavior.
