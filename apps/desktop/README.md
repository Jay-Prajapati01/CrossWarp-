# Desktop application

Tauri 2 and React/Vite shell. The frontend calls the local status command, accurately shows each capability as unavailable, and keeps pairing actions disabled until an authenticated service exists. It is not a connected product build.

## Commands

- `npm install`
- `npm run typecheck`
- `npm run web:build`
- `npm run dev` (native Tauri shell; requires the Windows C++ build tools)
- `npm run build` (native desktop bundle; packaging is currently disabled)
