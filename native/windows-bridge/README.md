# Windows bridge

Windows-native components live in focused subprojects. The Raw Input/`SendInput` bridge in [input-bridge](input-bridge/README.md) is linked into the Windows Rust agent. An opt-in local diagnostic counts event kinds; it does not forward input. The new window-capture static bridge enumerates visible titled windows and reads bounded BGRA frames through Windows.Graphics.Capture. The desktop can encode selected frames as bounded JPEG and send them over the authenticated window-video lane after source approval; the receiver independently asks for consent before previewing. This is a view-only stream foundation, not yet a movable/interactable portal. No receiving-side SendInput path, unified focus ownership, or display driver is active. See [feature status](../../docs/FEATURE_STATUS.md) and the [documentation index](../../docs/README.md).
